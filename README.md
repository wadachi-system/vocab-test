# 英単語確認テスト

スマホブラウザで動作する英単語確認テストです。GitHub Pagesで公開できます。

## 機能
- 範囲（開始番号〜終了番号）とモード（英→和 / 和→英）を選択
- ランダムに1単語出題
- 「答え」ボタンで訳を表示
- 「次へ」で別のランダム単語
- 常に「メニューに戻る」ボタンあり
- データ収集なし

## GitHub Pagesでの公開方法

1. GitHubで新しいリポジトリを作成（例: `vocab-test`）
2. このフォルダ内の以下のファイルをアップロード:
   - `index.html`
   - `words.json`
3. リポジトリの Settings → Pages で:
   - Source: Deploy from a branch
   - Branch: main / root
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセス可能

## ローカルで確認する場合
`index.html` をブラウザで直接開いても動作します（words.json が同じフォルダにあること）。

## 単語データ
`words.json` は元のCSVを整形したものです（全1235語）。
必要に応じて差し替え可能です。
